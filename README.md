# Fortune in a Pot

A kind, funny fortune for a houseplant — one line, 105 characters.

> "This week, the sun will find your favourite leaf, and you will grow an inch taller just to say thank you."

## Run it

```sh
npx tsx main.ts
cat /output/entry.txt
```

Writes the fortune to `/output/entry.txt`. Deterministic: a fixed line, no randomness, no clock, no network.
